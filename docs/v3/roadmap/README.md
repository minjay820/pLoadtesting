# Roadmap

This area stores issue-sized planning drafts and future-work breakdowns for pLoadtesting. These documents are not a substitute for implementation specs or runbooks; they help split larger work into reviewable units.

## Current Roadmap Drafts

- [Dashboard, API, and distributed deployment issue drafts](github-issues-dashboard-api-deployment.md)

## Usage

- Keep roadmap items small enough to become individual issues or pull requests.
- Link each item to the relevant active domain document, spec, or runbook.
- Do not place deployment values, credentials, or private targets in roadmap documents.
