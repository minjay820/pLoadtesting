# 2026-06-30

## GHCR Publish Workflow

- Added `.github/workflows/publish-ghcr.yml` to publish `ploadtesting-control-plane`, `ploadtesting-worker`, and `ploadtesting-target-apps` to GitHub Container Registry.
- Configured the workflow as manual `workflow_dispatch` with separate tag inputs for the three images so the current admin-ready control-plane tag can differ from worker and target-apps tags.
- Configured Docker Buildx multi-architecture publication for `linux/amd64` and `linux/arm64`.
- Configured package publication through the repository `GITHUB_TOKEN` with `packages: write`.
- Added OCI source and revision labels so the published packages can link back to the source repository cleanly.

## Publication Policy Update

- Updated `docs/v3/specs/repository-publication-policy.md` to document GHCR as the planned public image surface for `ploadtesting-control-plane`, `ploadtesting-worker`, and `ploadtesting-target-apps`.
- Documented the tracked GHCR workflow entrypoint, package naming convention, first-push package visibility review, and the rule that registry credentials stay out of tracked env files.
