## Control Plane Admin Host Settings Support

- Added env-driven Django admin-host hardening settings for downstream protected admin host deployments.
- Preserved current defaults when admin settings are unset: no trusted CSRF origins, no secure proxy SSL header, no forwarded host use, non-secure cookies, cookie path `/`, and no static root.
- Added parsing support for `DJANGO_CSRF_TRUSTED_ORIGINS`, `DJANGO_SECURE_PROXY_SSL_HEADER`, `DJANGO_USE_X_FORWARDED_HOST`, `DJANGO_SESSION_COOKIE_SECURE`, `DJANGO_CSRF_COOKIE_SECURE`, `DJANGO_SESSION_COOKIE_PATH`, `DJANGO_CSRF_COOKIE_PATH`, and `DJANGO_STATIC_ROOT`.
- Kept `DJANGO_ALLOWED_HOSTS` as the existing comma-separated host list source.
- Added WhiteNoise static serving support and build-time `collectstatic` output at `/app/staticfiles` so future admin-host deployments can expose only scoped Django admin static assets.
- Documented that admin host exposure still requires a separate access-control policy, scoped static route, owner-approved private runtime gate, and deployment smoke.
- Added unit coverage for env list parsing, boolean parsing, secure proxy header parsing, invalid proxy header rejection, and optional static-root parsing.
